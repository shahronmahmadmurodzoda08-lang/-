# Python — курси омӯзишӣ

15 дарси мавзӯӣ дар барнома: асосҳо, тағйирёбандаҳо, навъҳои маълумот, операторҳо, if/else, for, while, функсияҳо бо def/return, list, tuple/set, dict, str, файлҳо, try/except ва ООП.

Ҳар дарс дорои қоида, мисол ва машқ аст. Санҷиши машқҳо намунавӣ буда, калимаҳо ва сохторҳои асосии кодро месанҷад; он ивазкунандаи иҷрои воқеии Python нест.

Барои PDF-и иҷозатдодашуда аз папкаи `pdfs/` истифода баред. Хондани PDF дар дохили барнома ҳанӯз фаъол нест.
