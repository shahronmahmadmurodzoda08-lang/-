# BOOKS — Китобхона ва маркази омӯзиш

Ин ҷузвдон маркази тамоми маводи омӯзишии барномаи BOOKS мебошад.

## Китобҳо
- Фарҳангшиносӣ: нусхаи сканшудаи 251 саҳифа дар `assets/pages/` ва муқова дар `assets/cover.png`.
- Python: курси мавзӯӣ дар `BOOKS/python/`. Барои ҷойгир кардани PDF-и аслӣ аз `BOOKS/python/pdfs/` истифода баред.

## Қисмҳои барнома
- Китобхона ва ҷустуҷӯ
- Хонандаи китоб бо гузариши ду саҳифа/саҳифагардонии аниматсионӣ, zoom ва интихоби саҳифа
- Дарсҳои Python ва фарҳангшиносӣ
- Машқҳо бо санҷиши ҷавоб
- Тестҳои интихоби ҷавоб ва ҳисоб кардани хол

Матни дарсҳои Python дар ин лоиҳа маводи омӯзишии навтаълиф аст, на нусхаи пурраи ягон китоби муаллифӣ.
