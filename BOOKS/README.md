# BOOKS — Китобхона ва маркази омӯзиш

Папкаҳои лоиҳа:
- `python/` — курси Python ва ҷойи нигоҳдории PDF-и иҷозатдодашуда.
- `culture/` — маълумоти китоби фарҳангшиносӣ.
- `lessons/` — ҳуҷҷатҳои дарсҳо.
- `tests/` — ҳуҷҷатҳои санҷишҳо.

Китоби фарҳангшиносӣ аз 251 тасвир дар `assets/pages/` хонда мешавад. Курси Python аз 15 дарси навтаълиф иборат аст.

## Раванди илова кардани китоб
Ҳар китоб бояд ID-и ягона, сарлавҳа, тавсиф ва манбаи дорои ҳуқуқи истифода дошта бошад. Барои китобҳои тасвирӣ папкаи алоҳида дар `assets/books/<book_id>/` созед; баъд папкаи assets ва сабти китобро ба барнома илова кунед. Барои PDF аввал хонандаи мувофиқро ворид карда, санҷиши Android гузаронед. Дастури муфассал дар README-и асосӣ аст.
