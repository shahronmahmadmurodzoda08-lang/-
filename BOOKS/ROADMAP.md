# BOOKS — Нақшаи иҷрои марҳилавӣ

Ҳар марҳила танҳо баъд аз гузаштани санҷишҳои марҳилаи қаблӣ оғоз мешавад. Ҳадаф кам кардани хатогиҳо ва ҷудо кардани тағйирот аст.

## Алгоритми умумӣ
1. Тағйир додани як қисми хурд.
2. `flutter pub get`.
3. `dart format --set-exit-if-changed lib test`.
4. `flutter analyze`.
5. `flutter test` — тестҳои ҳамон хусусият ва регрессия.
6. `flutter build apk --release`.
7. Танҳо баъди сабз шудани ҳамаи қадамҳо гузаштан ба марҳилаи нав.
