# BOOKS — Китобхона

Барномаи Flutter бо интерфейси тоҷикӣ.

## Қисмҳои мавҷуда
- Фарҳангшиносӣ: 251 саҳифаи тасвирӣ, хондани офлайн, масштаб ва интихоби саҳифа.
- Python: 15 дарс аз асосҳо то ООП бо қоида, мисол ва машқ.
- Фарҳангшиносӣ: 5 дарси мавзӯӣ.
- Тест: 10 саволи тасодуфӣ бо ҷавоб ва ҳисобкунии хол.
- Алгебра ва физика: формулаҳо ва шарҳи кӯтоҳ.
- Китобҳои иловагӣ: илова кардани ном, муаллиф ва тавсиф; ҷустуҷӯ ва несткунӣ.
- PDF: интихоби файли PDF аз телефон, нусхабардорӣ ба хотираи дохилии барнома, нигоҳ доштани сабт ва кушодан бо хонандаи дохилӣ.

## Илова кардани китоб аз барнома
1. Дар саҳифаи асосӣ тугмаи `+` ё `Илова кардани китоб`-ро пахш кунед.
2. Ном, муаллиф ва тавсифро ворид кунед.
3. Навъи `PDF`-ро интихоб кунед, то файли PDF аз хотираи телефон интихоб шавад; ё навъи дигари китобро интихоб кунед.
4. Китобҳои иловашуда дар рӯйхат нишон дода мешаванд. Китоби PDF-ро пахш кунед, то кушода шавад.
5. Аз нишонаи сабад китобро нест кунед. Файли PDF-и вобаста низ аз хотираи дохилии барнома нест карда мешавад.

## Папкаҳо
- `BOOKS/python/` — маълумоти курси Python.
- `BOOKS/culture/` — маълумоти фарҳангшиносӣ.
- `BOOKS/lessons/` — ҳуҷҷатҳои дарсҳо.
- `BOOKS/tests/` — ҳуҷҷатҳои тестҳо.
- `assets/pages/` — 251 тасвири саҳифаҳои фарҳангшиносӣ.

## Маҳдудият
Дар версияи ҷорӣ китобҳои иловашуда ва файлҳои PDF дар хотираи дохилии барнома нигоҳ дошта мешаванд. Онҳо ба ҳисоби абрӣ ҳамоҳанг намешаванд ва ҳангоми нест кардани барнома метавонанд пок шаванд. PDF бояд аз тарафи корбар интихоб карда шавад; PDF-и аслии Python дар репозитория нест.
