# BOOKS — Китобхона ва омӯзиш

## Қисмҳои барнома
- Фарҳангшиносӣ: 251 саҳифаи тасвирӣ, хондани офлайн.
- Python: 15 дарси асосӣ аз тағйирёбандаҳо то ООП.
- Роҳҳои омӯзиши барномасозӣ: Python, C++, Java ва JavaScript; ҳар курс дорои дарс, мисол ва машқ аст.
- Тест: 10 саволи тасодуфӣ, ҳисобкунии хол ва таймери 15-сониягӣ барои ҳар савол. Ҷавоби дуруст бо сабз, ҷавоби нодуруст бо сурх нишон дода мешавад.
- Китобҳои шахсӣ: илова кардани унвон, муаллиф, тавсиф ва PDF аз телефон; ҷустуҷӯ, хондан ва нест кардан.

## Илова кардани PDF
1. Дар саҳифаи асосӣ `+` ё `Илова кардани китоб`-ро интихоб кунед.
2. Номи китобро нависед ва навъи `PDF`-ро интихоб кунед.
3. Файли PDF-ро аз телефон интихоб кунед.
4. Китоб дар китобхонаи шахсӣ нигоҳ дошта мешавад; онро пахш карда дар дохили барнома хонед.

## Файлҳои китоб
- `BOOKS/python/` — ҳуҷҷатҳои курси Python.
- `BOOKS/python/pdfs/` — ҷойи PDF-и китоби аслии Python.
- `BOOKS/culture/` — маводи фарҳангшиносӣ.
- `BOOKS/lessons/` — дарсҳо.
- `BOOKS/tests/` — тестҳо.
- `assets/pages/` — тасвирҳои 251 саҳифаи фарҳангшиносӣ.

## Китоби Python-и тақрибан 530-саҳифагӣ
PDF-и аслии китоб дар branch-и ҷорӣ нест. Барои дохил кардани ҳамон китоб, файли аслиро бояд бор кард ва ба `BOOKS/python/pdfs/` илова намуд. Курси 15-дарсии дохили барнома ҷойгузини он китоб нест.
