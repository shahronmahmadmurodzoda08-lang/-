# BOOKS — Китобхона

Барномаи Flutter бо интерфейси тоҷикӣ.

## Қисмҳои мавҷуда
- Фарҳангшиносӣ: 251 саҳифаи тасвирӣ, хондани офлайн, масштаб ва интихоби рақами саҳифа.
- Python: 15 дарс аз асосҳо то ООП бо қоида, мисол ва машқ.
- Фарҳангшиносӣ: 5 дарси мавзӯӣ.
- Тест: 10 саволи тасодуфӣ бо нишон додани ҷавоби дуруст ва ҳисоб кардани хол.
- Алгебра ва физика: формулаҳо ва шарҳи кӯтоҳ.

## Илова кардани китоб
1. Барои нусхаи саҳифавӣ папкаи `assets/books/<book_id>/` созед.
2. Тасвирҳоро пайдарпай номгузорӣ кунед: `001.jpg`, `002.jpg` ва ғайра.
3. Папкаи китобро ба бахши `assets` дар `pubspec.yaml` илова кунед.
4. Барои китоб вуруд дар рӯйхати китобҳо ва намоишгари мувофиқ созед.
5. `flutter pub get`, `flutter analyze`, `flutter test` ва `flutter build apk --release` иҷро кунед.

## PDF ва маҳдудият
Дар версияи ҳозира интихоби PDF аз хотираи телефон ва хонандаи дохилии PDF фаъол нест. Барои илова кардани он, плагини бо Android compileSdk-и лоиҳа мувофиқ интихоб ва дар CI санҷида шавад. PDF-и аслии Python ҳоло ба репозитория бор нашудааст.

## Санҷиш
`flutter test` санҷиши экрани китобхона, дарс, хонандаи фарҳангшиносӣ ва оғози тестро иҷро мекунад.
