# BOOKS — Китобхона

Барномаи Flutter бо интерфейси тоҷикӣ.
- Фарҳангшиносӣ: 251 саҳифаи сканшуда, zoom, интихоби саҳифа ва гардиши 3D-аниматсионӣ.
- Python: 15 дарс аз асосҳо то функсияҳо, рӯйхатҳо, файлҳо, хатогиҳо ва ООП.

- Кушодани PDF аз хотираи телефон.
- Дарсҳои иловагии алгебра ва физика.

Оғоз: flutter pub get && flutter analyze && flutter test && flutter run
